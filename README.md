# ApartmentRental — Комплекс управления арендой недвижимости

Проект разработан в рамках учебной практики (ПМ.03).  
Автор: **Шивырталов Дмитрий** (гр. ИСП 32-9, вариант 19).

---

### О проекте

Десктопное приложение для риелторских агентств и частных арендодателей, позволяющее вести базу жилья, подбирать варианты по критериям арендатора, оформлять сделки и анализировать окупаемость инвестиций в жилую недвижимость.

Стек: **C# / Windows Forms / .NET Framework 4.8 / MS Access (ACE.OLEDB)**.

---

### Структура проекта и этапы разработки

#### 📌 Этап 1. Базовый релиз (v1.0) — папка `ApartmentRental_v1`
Стартовая версия с основным операционным функционалом:
- Учет фонда квартир: район, площадь, этажность, стоимость аренды в месяц.
- Добавление, редактирование и снятие с публикации объектов жилья.
- Оформление сделок найма с фиксацией дат заезда и выезда.
- Хранение информации в локальном файле базы данных `rental.accdb`.

#### 📌 Этап 2. Финальный релиз с авторизацией и аналитикой (v2.0) — папка `ApartmentRental_v2`
Завершенное решение с ролевой моделью и финансовым моделированием:
- **Разграничение доступа:**
  - `admin` (пароль `admin123`) — полное управление объектами, клиентами и системными настройками.
  - `realtor` (пароль `realtor123`) — каталог, сопровождение договоров, база нанимателей.
  - `client` (пароль `client123`) — подбор жилья и просмотр оформленных договоров.
- **Интеллектуальный фильтр:** поиск по районам города, бюджету аренды, числу комнат, наличию мебели/техники и балкона.
- **База нанимателей:** карточки физических и юридических лиц с контактными данными и паспортными реквизитами.
- **Экспорт отчетности:** выгрузка журнала договоров и активных объявлений в формат CSV (для Excel).
- **Математический эксперимент (Анализ окупаемости жилья):**
  - Расчет чистого операционного дохода (NOI).
  - Оценка ставки капитализации (Cap Rate) и возврата инвестиций (ROI %) при различных сценариях занятости (Occupancy Rate).
  - Автоматическая генерация рекомендаций для собственников и инвесторов.

### Архитектура данных (`rental.accdb`)

База данных включает 5 реляционных таблиц:
1. `Users` — учетные записи персонала и клиентов с ролевыми привилегиями.
2. `Districts` — справочник районов города со средней рыночной ставкой.
3. `Apartments` — реестр квартир со всеми техническими характеристиками.
4. `Clients` — картотека клиентов (арендаторов).
5. `Rentals` — журнал договоров найма жилья с расчетом депозита и комиссии.

### Быстрый запуск

1. Склонировать репозиторий:
   ```bash
   git clone https://github.com/RuusselL-me1/UP-PM-03.git
   ```
2. Открыть решение `ApartmentRental_v2.sln` в Visual Studio 2022 (или выше).
3. Убедиться, что в системе установлен **Microsoft Access Database Engine 2010/2016** (для взаимодействия через OLE DB).
4. Запустить сборку в конфигурации `Release` (клавиша F5).
